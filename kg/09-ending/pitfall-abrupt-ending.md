**Bottom line:** An ending that is not prepared wastes the consolidation phase that protects gains. The fix is simple and cheap: name the ending at the start, open the ending phase several sessions early, space sessions out, and hand over a written plan the client has already tested [Beck-2021; NICE-NG222].

## What it looks like

- The client finds out in the last session that it is the last session.
- Sessions stay weekly to the end, so the client has never coped alone between them.
- No written plan exists, or the therapist hands over a generic leaflet.
- The final session is a normal session with "good luck" at the end.
- The client says "I don't know what I'll do without you" and the comment is not explored.
- There is no named route back, so a later setback becomes a new referral and a long wait.

## Why it happens

- Session counts are set by a service or payer, and the end date is treated as administrative.
- Endings stir up feelings in the client and the therapist, and both may avoid them, even though processing those feelings is a core termination task in expert consensus [Norcross-etal-2017].
- Content work fills every session, and relapse prevention is left for "next time."
- The therapist assumes skills learned in session will transfer on their own.

## The fix

- If you are in session 1 → say that cognitive behavioral therapy (CBT) is time-limited and aims to make the client their own therapist. Because preparing for the end starts at the beginning [Beck-2021].
- If a few sessions remain and the ending has not been discussed → raise it today. "We have four sessions left. I'd like us to use them to make sure you can keep this going without me." Because explicit preparation for termination is a core task across therapies [Norcross-etal-2017].
- If sessions are still weekly near the end → agree to space them and plan self-therapy sessions in the gaps. Because a spaced schedule lets the client test their coping before therapy stops [Beck-2021].
- If there is no written plan → build one with the client, covering what helped, early warning signs, high-risk situations and a setback plan. Because the National Institute for Health and Care Excellence (NICE) lists these as relapse prevention components [NICE-NG222].
- If the client credits you for the change → ask what they did differently. Because self-attribution of change builds confidence to cope alone [Beck-2021].
- If the end date is forced by a payer → still give a pre-ending discussion and alternatives. Because this is an ethical requirement unless the payer or client prevents it [APA-Ethics-2017].

## Sources note

Trials test relapse prevention programs as a whole: psychological relapse prevention reduced depressive relapse by about 22% at 12 months compared with controls [Clarke-etal-2015]. No trial has isolated tapering or the final session itself, so those parts rest on expert consensus [Norcross-etal-2017; Beck-2021].
