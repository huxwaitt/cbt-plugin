**Bottom line:** A formulation is a hypothesis, so it has to be tested and changed. Review it with the client at set points and whenever progress data surprise you. Poor progress is a signal to re-examine the formulation, not only to try another technique.

## What it looks like

- The diagram has one date on it, from the second session.
- Scores have not moved for five sessions, and the plan is the same.
- The client disclosed something important (drinking, a trauma, a relationship problem) and the formulation does not mention it.
- Session notes describe techniques but never say whether the predicted change happened.

## Why it happens

- Formulation is seen as an assessment task that ends when treatment starts.
- No session-by-session measure, so no signal that the formulation is wrong.
- Revising feels like admitting a mistake.
- Busy sessions crowd out review.

## The fix

- If you are starting treatment → write the prediction the formulation makes and the measure that will test it. Because Persons treats the formulation as a hypothesis tested by progress data [Persons-Tompkins-2022].
- If you see the client each week → collect a brief measure every session and look at it together. Because the feedback element has the strongest evidence in formulation-driven cognitive behavioral therapy (CBT) [Persons-Hong-2016].
- If scores stall or worsen → gather more assessment data and consider an alternative formulation with different targets. Because poor progress suggests the formulation may be incorrect [Persons-Tompkins-2022].
- If new information emerges → update the diagram in the session with the client. Because assessment and treatment are an ongoing process of testing and revising formulations [Macneil-etal-2012].
- If you reach a phase change (start, middle, end, booster) → revisit the level of the formulation. Because formulation is expected to evolve from descriptive to explanatory over therapy [Kuyken-etal-2008].
- If you review intervention results → interpret them in light of the formulation. Because competent practice links treatment planning to the formulation and reviews results against it [Padesky-etal-2011].

Practical habit: keep the formulation where you will see it in every session. Persons describes writing it on colored paper so it can be pulled from the record and revised during the session, or editing it live in an electronic record [Persons-Tompkins-2022].

Example phrasing: "Our map said avoiding calls kept the low mood going. You've made more calls, but the scores haven't changed. What might we have missed?"

## Sources note

Based on the hypothesis-testing model and evidence for measurement-based feedback. No trial has isolated formulation revision itself.
